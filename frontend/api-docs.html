Overview

The FakeDetector API is a REST API running locally at http://127.0.0.1:8000. All endpoints accept multipart/form-data and return application/json.

● Online Base URL: http://127.0.0.1:8000
Docs http://127.0.0.1:8000/api/docs →
# Health check
curl http://127.0.0.1:8000/api/health

# Response
{"status": "ok", "version": "1.0.0"}

Detect Text

POST /api/detect/text

Analyze plain text content for the specified detection type.

Form Parameters

Field Type Description
text string The text content to analyze (min 20 chars)
detection_type string One of the detection type values (see Types)

Example Request

# cURL example
curl -X POST http://127.0.0.1:8000/api/detect/text \
  -F "text=This article was written by an advanced AI language model..." \
  -F "detection_type=ai_content" curl

Detect URL

POST /api/detect/url

Fetch and analyze the content at a given URL.

Example Request

curl -X POST http://127.0.0.1:8000/api/detect/url \
  -F "url=https://example.com/suspicious-article" \
  -F "detection_type=fake_news" curl

Detect File

POST /api/detect/file

Upload and analyze a file. Supports .txt, .pdf, and .docx.

Example Request

curl -X POST http://127.0.0.1:8000/api/detect/file \
  -F "file=@/path/to/document.pdf" \
  -F "detection_type=plagiarism" curl

Scan History

GET /api/history

Retrieve scan history. Optional ?limit=50 parameter.

curl http://127.0.0.1:8000/api/history?limit=20 curl
GET /api/history/{id}

Retrieve a single scan result by ID.

DELETE /api/history/{id}

Delete a scan from history.

Detection Types

Use these values for the detection_type parameter:

"ai_content" // AI-generated text detection
"plagiarism" // Originality & plagiarism check
"fake_news" // Fake news & misinformation
"fake_review" // Fake/bot review detection
"fake_profile" // Fake social profile detection
"fake_job" // Scam job posting detection
"phishing" // Phishing email detection
"code_plagiarism" // Code plagiarism / AI code

Response Format

All detection endpoints return the same structured JSON response:

{
  "detection_type": "ai_content",
  "score": 87, // 0-100, higher = more fake/AI
  "verdict": "Likely AI Generated",
  "confidence": "High", // High | Medium | Low
